Neovim 是一个快速且可扩展的编辑环境，配合少量插件与 LSP 客户端后，非常适合编程工作。本文展示一个现代且最小化的配置示例，不强制使用特定的插件管理器。

## 最小化 `init.lua`

将文件放到 `~/.config/nvim/init.lua`：

```lua
-- minimal init.lua
vim.o.number = true
vim.o.expandtab = true
vim.o.shiftwidth = 2

require('plugins') -- 将插件拆分到单独文件
require('lsp')
```

这种分离有助于保持核心设置简洁，并把插件配置单独管理。

## 语言服务器协议（LSP）

使用 `nvim-lspconfig` 将 Neovim 连接到语言服务器。示例（Python / Lua）：

```lua
local lspconfig = require('lspconfig')
lspconfig.pyright.setup({})
lspconfig.lua_ls.setup({})
```

## 插件与插件管理器

常见的插件管理器包括 `lazy.nvim` 与 `packer.nvim`。对于开发，推荐的精简插件集合包括：LSP 客户端、补全引擎（nvim-cmp）、treesitter 语法以及文件浏览器。

## 测试配置

打开一个项目并确认：

1. 诊断会显示语法/类型错误。
2. `gd` 或 `vim.lsp.buf.definition()` 能跳转到符号定义。
3. 补全建议在输入时自动弹出。
