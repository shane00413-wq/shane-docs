平铺式窗口管理器以键盘为中心管理窗口布局，资源占用低，适合追求高效工作流的开发者。常见的有基于 X11 的 `i3` 和基于 Wayland 的 `sway`。

## 基本概念

- 工作区（workspaces）：用于分组窗口的虚拟桌面。
- 平铺（tiling）：窗口自动调整大小以填满可用空间。
- 浮动窗口：用于对话框或需要自由移动的应用。

## 最小 i3 配置示例

将配置放到 `~/.config/i3/config`：

```
set $mod Mod4
bindsym $mod+Return exec alacritty
bindsym $mod+d exec dmenu_run
workspace 1 output HDMI-1
```

## 入门步骤

1. 从包管理器安装 `i3` 或 `sway`。
2. 创建最小配置，绑定终端和启动器。
3. 学习工作区切换与窗口移动的快捷键。

<Aside type="tip" title="在 VM 或独立会话中尝试">
在虚拟机或独立用户会话中测试新的窗口管理器，以免在学习过程中失去对工作环境的访问权限。
</Aside>

## 平铺窗口管理器带来的变化

平铺窗口管理器改变了窗口在屏幕上的排列方式，通常用键盘驱动的布局取代传统桌面环境中浮动、重叠的窗口模型。这种方式在需要同时管理多个窗口时，可以显著减少频繁使用鼠标的开销。

## 如何安全地开始

如果你刚接触平铺窗口管理器，建议先在独立的登录会话中尝试，而不是直接替换主桌面。安装 `i3` 或 `sway` 后，创建一个专门的 `.xsession` 或 `.desktop` 条目，这样登录时可以选择它。若需要返回 GNOME/KDE/MATE，正常桌面仍然可用。

## 一个实际例子：i3 中切换焦点

在 `i3` 中，通常用 `Mod1+hjkl` 或 `Mod1+方向键` 切换窗口焦点，用 `Mod1+Shift+<数字>` 将窗口移动到不同工作区。学习这些快捷键往往是入门时最大的门槛，但养成习惯后，效率会大幅提升。
